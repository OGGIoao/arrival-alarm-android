# Android 原生版

这是“别坐过站”的 Android 原生实现，最低 Android 8.0（API 26），不依赖 Gradle、AndroidX、Google Play Services 或第三方 SDK。

## 构建

需要 Android Platform 36 和 Build Tools 36.0.0：

```powershell
.\android-app\build-apk.ps1 -SdkRoot "C:\path\to\android-sdk"
```

脚本会先运行纯 Java 核心测试，再编译、DEX、对齐并使用本机生成的稳定调试证书签名。证书保存在已忽略的 `android-app/.signing/`，便于后续覆盖安装；APK 输出到同样已忽略的 `outputs/arrival-alarm-debug.apk`。不要公开调试证书，正式发布时请使用单独的发行签名。

## 已实现

- iOS 风格的分组背景、系统蓝主操作、圆角卡片、开关式设置和即时按压/触觉反馈。
- 原生单页地点输入；输入简称时即时匹配最近/固定地点并异步显示候选。默认自动调用 Photon/OpenStreetMap POI 服务，不要求用户配置 Key；开发者构建时若提供应用级高德 Key则优先使用高德，最后回退系统 `Geocoder`。
- 联想搜索采用 100–180 毫秒可取消防抖、双后台线程和 32 项会话缓存；旧请求结果不会覆盖新关键词。
- v0.4.1 将联想等待缩短到 100–180 毫秒，取消的排队任务会立即移除；系统搜索只保留与关键词高度相关的候选，避免展示“场”之类被错误拆分的地点。
- 适配 Android 15+ 强制 edge-to-edge：标题、设置按钮和滚动内容会使用状态栏、刘海及底部导航栏安全区，不再与系统图标重叠；键盘弹出时使用可调整窗口。
- 高德返回的 GCJ-02 坐标会在本机转换后再参与到站距离计算，避免坐标系偏移直接影响提醒半径。
- 固定地点闹钟：最多 6 个工作日或每日通勤日程，在用户设置的出发时间自动预设目的地并开始到站监控；支持暂停、恢复、删除和重启后恢复调度。
- Android 12+ 有“闹钟和提醒”权限时使用精确系统闹钟；没有时保留日程并使用非精确定时。缺少后台位置或系统阻止后台启动时改发点按开启通知。
- 接收地图/打车软件的 `text/plain` 系统分享，以及 `arrivalalarm://set` 深链。
- 识别常见地图 URI、经纬度和被选中的地点文字；外部坐标启动前反查地址并要求用户确认。
- 可选“使用情况访问”只检查支持的地图/打车 App 是否刚被打开，在本机提示设置目的地，不读取页面内容。
- 可选“通知使用权”在内存中过滤受支持来源的导航、交通卡、地铁、高铁进站/检票信号，不保存通知正文。
- 可选车站附近检测每隔数分钟通过手机系统地理编码反查当前位置，识别地铁站、火车站和高铁站名称；不使用自建云端。
- 注册常见地图、12306 和打车网站的 Android 链接入口；第三方域名无法由本应用验证，是否交给本 App 仍由系统默认链接设置决定。
- 若网站仍由浏览器打开，应用不会读取网址；只有在已检测到出行且浏览器刚打开时发出通用设置提醒。
- Android 前台定位服务；任何一次可靠定位进入或落在预设半径内都会立即触发到站闹钟，不再等待第二次确认。
- 高优先级全屏通知、声音、振动和“我已到达”操作；每 30 秒重复，最多 5 分钟。
- 可选低频乘车检测：离开 500 米锚点后，以速度和位移确认乘车，同一行程只提示一次。
- 最近地点、提醒半径、本机清空和隐私说明。

## 隐私

应用声明 `INTERNET` 权限用于地点联想，没有账号、自建后端、广告或分析。关键词和可选的附近坐标会直接发送给 Photon/OpenStreetMap，或开发者构建时配置的高德服务；搜索缓存、固定日程和历史记录只保存在本机，不写入日志。可选的使用情况访问只在内存中过滤受支持的出行 App 包名，不保存完整历史。

## 限制

- 用户无需配置地图 Key。开发者若有高德 Web 服务 Key，可在构建前设置环境变量 `ARRIVAL_AMAP_WEB_KEY`；密钥会由构建脚本注入 APK，不出现在设置页。
- Photon 公共服务只适合合理用量并可能限流；正式大规模发行应部署自己的 Photon 实例，或使用由开发团队统一管理、绑定应用身份的商业地图服务。
- Android 11+ 要在系统应用权限页把位置设为“始终允许”，固定日程才可在应用不在前台时直接开始位置监控；否则会尽量发通知要求点按开启。
- Android 12+ 若未允许“闹钟和提醒”，系统可能推迟固定日程的启动时间。
- 车站附近识别同样依赖系统 `Geocoder`，属于尽力而为；系统没有返回车站名称时不会触发。
- 实体交通卡直接刷闸机且手机没有产生通知时，普通 Android App 无法获知刷卡事件；本功能依赖手机钱包、地图或铁路应用实际发出可识别通知。
- Android 14+ 可能需要用户在系统设置中允许全屏闹钟通知；否则仍会显示高优先级通知、声音和振动。
- 厂商省电、强制结束应用、关闭定位、静音/勿扰或地下无信号都可能影响提醒，不能宣传为百分之百触发。
